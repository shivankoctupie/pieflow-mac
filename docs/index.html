Talk instead of typing, in any Mac app.

Hold fn, speak, let go. PieFlow turns what you said into clean text right where your cursor is. It is free, open source, and can run fully offline.

Download for Mac Source on GitHub

Free. macOS 14 or later, Apple silicon and Intel.

Voice typing that works where you already write

Mail, Slack, WhatsApp, your code editor, a search box. PieFlow pastes at the cursor, so there is nothing to copy across.

It removes the ums, fixes punctuation, and handles "Tuesday, no wait, Friday" the way you meant it.

  • Hold fnDictate, release to finish
  • Double tap fnHands-free, press again to stop
  • EscCancel
  • Select text, then ⌥ 1Polish what you wrote

Fast in the cloud, private on your Mac

Use Groq or xAI with your own API key for the quickest, most accurate results. Or download a Whisper model and dictate with no internet and no key.

Have both, and PieFlow uses the cloud first. If it has not answered in about two seconds, the local model steps in, so a bad connection never leaves you waiting.

Meeting notes without a bot in the call

Notetaker records your microphone and the other side of the call straight from your Mac. Nobody else sees a recorder join.

You get a live transcript, then a summary with action items and key points. It can start by itself when a call begins.

Install in two minutes

  1. Download the DMG and drag PieFlow into Applications.

    Get the latest release from GitHub.

  2. Open it, then allow it once.

    PieFlow is not notarized by Apple, so macOS blocks the first launch. Click Done, open System Settings, go to Privacy & Security, scroll down and click Open Anyway. Or run this in Terminal:

    xattr -dr com.apple.quarantine /Applications/PieFlow.app
  3. Allow Microphone and Accessibility.

    Accessibility is what lets PieFlow see the fn key and paste text for you.

  4. Pick an engine.

    Paste a key from Groq or xAI, or download a local Whisper model to work offline.

Your words stay yours

  • No account, no analytics, no tracking.
  • History, notes and API keys are stored only on your Mac.
  • Audio leaves your Mac only for the cloud engine you chose. With a local model and no keys, nothing leaves at all.
  • The code is open, so you can read exactly what it does or build it yourself.

Questions

Is PieFlow really free?

Yes. The app is free and MIT licensed. Local Whisper costs nothing. If you use a cloud engine, you bring your own key and pay that provider directly; Groq has a free tier.

Does it work offline?

Yes. Download one of the local Whisper models in Settings (142 MB to 547 MB) and dictation runs entirely on your Mac.

Which Macs does it run on?

Any Mac on macOS 14 Sonoma or later, Apple silicon or Intel.

Which languages can I dictate in?

Pick a language in Settings or let it detect one. Groq Whisper and the Large v3 Turbo local model handle many languages, including Hindi, Spanish, French, German, Japanese and Chinese. The two smaller local models are English only.

Why does macOS say it cannot verify the app?

Apple shows that for any app that has not been through its paid notarization programme. PieFlow has not, yet. The install steps above get you past it once, and the source is public if you would rather build it yourself.

Is this Wispr Flow?

No. PieFlow is an independent open source project that started as a free alternative to Wispr Flow. It is not affiliated with Wispr Flow, Groq, xAI or OpenAI.
